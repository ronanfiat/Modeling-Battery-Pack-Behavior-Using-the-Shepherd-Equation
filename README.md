# Modeling-Battery-Pack-Behavior-Using-the-Shepherd-Equation
Research Project Carried out under Eric Stuve at the University of Washington Chemical Engineering Department. This code models battery pack behavior, taking advantage of iteration tools in python. This code is intended to be used in Jupyter Notebooks.

This project is under development, and is not fully up to date. Full documentation, updates to the code, and additional features will be added in future.
